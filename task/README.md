# Задание на проектную практику

## Вариативная часть (выбрана)

**Практическая реализация технологии** - разработка Telegram-бота для анонимных сообщений.

### Формулировка задания
Разработать бота на Python, который:
- Принимает текстовые сообщения в личку.
- Публикует их анонимно в Telegram-канал.
- Ограничивает частоту отправки: антиспам.
- Ограничивает длину сообщения.
- Сохраняет все сообщения в SQLite.
- Имеет команды `/start`, `/help`.

### Критерии оценки
- Бот работает без ошибок.
- Код читаемый, разделён на функции.
- Присутствует документация.
- Репозиторий заполнен по заданной структуре.
