## 2. Характеристика организации (заказчика)
Московский политех, кафедра информатики и информационных технологий.

## 3. Описание задания по практике
Индивидуальное задание на проектную практику:
Разработать Telegram-бота на языке Python со следующим функционалом:
- Приём текстовых сообщений от пользователей в личные сообщения бота.
- Анонимная публикация полученных сообщений в заранее определённый канал или группу.
- Защита от спама.
- Хранение всех сообщений в базе данных с указанием идентификатора отправителя, имени и времени отправки.
- Поддержка служебных команд: /start - приветствие, /help - справка.
- Обработка ошибок и ограничений.
- Документирование кода и подготовка пояснительной записки.

## 4. Достигнутые результаты
- Разработан бот.
- Реализованы функции: анонимная отправка, антиспам, БД.
- Проведено тестирование.

## Заключение
Все задачи выполнены. Бот может использоваться для анонимных опросов и обратной связи.
