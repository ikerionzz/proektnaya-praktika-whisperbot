## Возникшие проблемы и решения
| Проблема | Решение |
|----------|---------|
| Бот не видел ID канала, выдавал ошибку `chat not found` | Получил ID через пересылку сообщения боту `@userinfobot` |
| Бот не отправлял сообщения в канал | Добавил бота в администраторы канала и дал право на отправку |
| Пользователи спамили | Внёс антиспам с задержкой 10 секунд и хранением времени последнего сообщения в БД |
