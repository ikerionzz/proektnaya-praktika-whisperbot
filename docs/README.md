# Документация по проекту

## Описание процесса выполнения практики

### Выбор технологий
- **Язык программирования:** Python 3.13
- **Библиотека для Telegram API:** PyTelegramBotAPI - выбрана за простоту и хорошую документацию.
- **База данных:** SQLite - встроенная, не требует отдельного сервера.

### Архитектура бота
- Модуль конфигурации (токен, ID канала, параметры антиспама).
- Модуль базы данных (инициализация таблиц, сохранение сообщений, проверка на антиспам).
- Модуль обработчиков команд (`/start`, `/help`).
- Модуль обработки текстовых сообщений (валидация длины, антиспам, публикация).

### Основные функции
| Функция | Описание |
| Анонимная публикация | Сообщение уходит в канал без имени отправителя |
| Антиспам | Нельзя отправить новое сообщение раньше чем через 10 секунд |
| Ограничение длины | Максимум 1000 символов |
| Сохранение в БД | Каждое сообщение сохраняется с user_id, именем и временем |

### Инструкция по запуску
1. Установите Python 3.10 или выше.
2. Установите библиотеку: `pip install pyTelegramBotAPI`
3. Получите токен бота у `@BotFather`.
4. Создайте канал, добавьте бота в администраторы.
5. Укажите токен и ID канала в файле `src/bot.py`.
6. Запустите бота: `python src/bot.py`
