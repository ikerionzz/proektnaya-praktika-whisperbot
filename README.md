## Наименование проекта по «Проектной деятельности»
WhisperBot - анонимный бот-исповедник для Telegram

## Формулировка задания вариативной части
Разработать Telegram-бота на языке Python, который:
- принимает текстовые сообщения от пользователей в личные сообщения;
- публикует их анонимно в заданный Telegram-канал;
- реализует защиту от спама;
- ограничивает длину сообщения;
- сохраняет все сообщения в базу данных SQLite;
- поддерживает команды /start, /help.
